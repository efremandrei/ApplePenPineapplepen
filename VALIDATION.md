# v0.2.0 verification

The initial APK is built with the Android SDK tools directly because this workspace cannot download Gradle/Maven dependencies. The normal Gradle project and GitHub Actions workflow are included for standard development.

Verified locally:

- Java source compilation against Android API 36.
- Resource and manifest compilation with AAPT2.
- DEX generation with D8 for API 30+.
- APK alignment and APK signature verification.
- 27 JUnit regression tests cover the initial scanner, HTTP and TLS fixtures, custom-port HTTP and SSH observation, protocol scope validation, opt-in lookup orchestration, exact CPE version/vendor matching, NVD fixture decoding and severity, bounded/strict JSON parsing, conservative comparison, comparison exports, and deserialization of a synthetic report generated by the original v0.1.0 classes.
- The delivered APK keeps the original signing certificate and increments the version code to 2.

The network integration tests use local loopback fixtures only. No public destination was scanned.

GitHub Actions separately runs Gradle unit tests, lint, and APK assembly, followed by an Android 16 emulator smoke test of the shipped APK. The smoke test installs v0.1.0 then v0.2.0, scans an owned fixture on a custom HTTP port, checks history/rescan, and exercises PDF/HTML/JSON exports. Screenshots, exported fixture reports, UI XML, and logcat are retained as a workflow artifact. The run's actual outcome is authoritative; adding a smoke job does not itself establish that it passed.

Not yet verified on a physical phone: manufacturer-specific battery behavior and device-specific document providers. NVD parser/lookup behavior is covered with deterministic fixtures; live NVD availability is not a release gate. Failed or incomplete live lookups are recorded without a vulnerability conclusion.

The shipped artifact is a development-signed universal APK with no native ABI dependency. Its SHA-256 checksum is in `downloads/SHA256SUMS`.
